# Здоровье → приложение: команда «Планировщик» (основной способ, бесплатно)

iOS не даёт сайтам читать «Здоровье» (туда пишет Huawei Health). Поэтому его читает ваша команда «Планировщик» и отправляет в облако (Apps Script), а приложение при открытии само забирает данные. Команда шлёт **сырые** отрезки сна — сервер сам объединит дубли источников и посчитает стадии.

> Важно: адрес из приложения (вкладка **Здоровье → «Адрес для команды»**) уже содержит токен и ваш часовой пояс. Цифры вручную в ссылку вписывать не нужно — раньше именно из-за этого команда слала одни и те же значения.

## Сборка команды (≈10 минут, один раз)
Откройте команду «Планировщик», старые действия «Открыть URL» с цифрами и «Остановить и получить…» удалите, затем:

1. **Найти образцы «Здоровья»** — Тип: *Сон*; Дата начала: *в последние 1 дн.*; сортировка: *Дата начала*, по возрастанию.
2. **Повторить с каждым** элементом из шага 1. Внутри — **Текст**: `[Дата начала] | [Дата окончания] | [Значение]`.
   У каждой даты нажмите на переменную → **Формат даты → Пользовательский** → `dd.MM.yyyy HH:mm` (время обязательно!). Затем **Добавить в переменную** → `sleepLines`.
3. После цикла: **Объединить текст** (`sleepLines`, разделитель — *Новая строка*) → **Задать переменную** `sleep`.
4. **Найти образцы** — *Шаги*, Дата начала: *сегодня* → **Рассчитать статистику: Сумма** → **Задать переменную** `steps`. Так же *Активная энергия* → `calories`.
5. **Найти образцы** — *Пульс*, в последние 20 ч, сортировка по *Значению* по возрастанию, ограничение 1 → **Получить сведения: Значение** → `hr` (минимум за ночь ≈ пульс покоя).
6. **Получить содержимое URL** — адрес вставьте из приложения (кнопка «📋 Скопировать ссылку для команды»), метод **POST**, тело запроса **JSON**, поля:

   | Поле | Значение |
   |---|---|
   | `sleep` | Текст → переменная `sleep` |
   | `steps` | Число → `steps` |
   | `calories` | Число → `calories` |
   | `hr` | Число → `hr` |

7. **Показать уведомление**: `Здоровье отправлено: [Содержимое URL]`. При проверке в ответе должно быть `"ok":true` и `"warnings":[]`. Позже уведомление можно удалить.
   Шаг «Открыть URL» **не нужен**: приложение подтягивает данные само при запуске.
8. При первом запуске разрешите команде доступ к *Сну, Шагам, Активной энергии и Пульсу*.

## Автозапуск
*Команды → Автоматизация → «+» → Личная автоматизация*:
- **Будильник → Остановлен** → Запустить «Планировщик» → **Запускать сразу** (основной: телефон только что разблокирован).
- **Время суток 08:30, ежедневно** → Запустить «Планировщик» → **Запускать сразу** (запасной).

Пока iPhone заблокирован, iOS не отдаёт данные «Здоровья» никому — поэтому надёжнее срабатывает вариант с будильником. Если Huawei Health ещё не успел записать ночь в «Здоровье», запустите команду чуть позже (кнопка «Запустить команду» есть в подсказке на главном экране приложения).

## Если не получается
| Ответ сервера / симптом | Причина → решение |
|---|---|
| `sleep_dates_unrecognized` | в дате нет времени или другой формат → шаг 2: `dd.MM.yyyy HH:mm` |
| `sleep_no_fresh_session` | в «Здоровье → Сон» нет записи за последние 20 ч (старше сервер не берёт, чтобы вчерашний сон не выдавался за сегодняшний) |
| `no_recognized_data` | поля JSON названы иначе: нужны `sleep`, `steps`, `calories`, `hr` |
| `auth` | токен в адресе не совпадает → заново скопируйте адрес из приложения |
| Шаги отличаются от Huawei Health | Здоровье → Обзор → Шаги → *Источники данных и доступ* → поставьте Huawei Health выше iPhone (команда суммирует все источники подряд) |

Что сервер получил последним: `ВАШ_URL/exec?action=raw&token=ТОКЕН` в браузере (GET покажет сырой запрос), статус: `…action=status…`.

## Запасной вариант (платный, без сборки команды): Health Auto Export
Приложение читает «Здоровье» само и раз в час шлёт данные. В нём: **Automations → + → REST API**, URL — из карточки «🤖 Автозагрузка» в приложении, метод **POST**, формат **JSON**; метрики: *Sleep Analysis, Step Count, Active Energy, Resting Heart Rate, Heart Rate*; Aggregate Data — вкл., интервал *Days*; Period — *Today*; каденция — каждый час. Автоматизации входят в платную часть — цену смотрите в App Store.

## Безопасность
Токен — как пароль. Если он попал на скриншот: в Apps Script запустите **`resetToken()`** → «Новая версия» развёртывания → вставьте новый токен в приложение и заново скопируйте адрес в команду. На экране приложения токен скрыт (••••), копируется полный адрес.
