# Ритм Дня v5.0 — быстрый запуск (iPhone 16 Pro Max)

Что получится: приложение на рабочем столе во весь экран; **Google Календарь** (события на сегодня) и **Google Задачи** подтягиваются сами, выполненные задачи уходят обратно в Google; данные «Здоровья» приходят утром автоматически; везде одна кнопка **🔄**.

## 1. Google (5 минут, один раз)
1. https://script.google.com → ваш проект → вставьте новый **`Code.gs`** вместо старого.
2. ⚙ **Настройки проекта** → включите «Показывать файл манифеста appsscript.json» → откройте его и замените содержимое файлом **`appsscript.json`** (он включает Google Tasks API). Сохраните 💾.
3. Вверху выберите функцию **`setup`** → **Выполнить** → разрешите доступ (Диск, **Календарь**, **Google Задачи**): «Дополнительно → Перейти (небезопасно)» — это ваш собственный скрипт.
4. В «Журнале выполнения» должно быть: `Календарь: OK`, `Google Задачи: OK` и ваш **токен**.
5. **Развернуть → Управление развёртываниями → ✏ → Версия: «Новая версия» → Развернуть** (ссылка `/exec` не меняется).

## 2. GitHub
Распакуйте `ritm-dnya-v5.zip` (в «Файлах» на iPhone: долгое нажатие → «Распаковать»; GitHub сам zip не распаковывает) и загрузите **все файлы** (кроме `Code.gs`, `appsscript.json`, `.md`) в репозиторий `my-steps-app`: **Add file → Upload files → Commit changes**.
Нужны: `index.html, script.js, style.css, sw.js, manifest.json, icon-180/192/512.png, splash-*.png`.

## 3. iPhone
1. Откройте сайт в Safari → **Поделиться → На экран «Домой»**.
2. Откройте иконку → на главном экране карточка **«Подключите Google»** → «Подключить» → в поле «Код подключения» вставьте **ссылку `/exec` и токен** (через пробел или с новой строки; удобно подготовить заметку). Подключение произойдёт само, календарь и задачи загрузятся.
3. Нужно подключить второе устройство/Safari? В подключённом приложении нажмите **🔑** (копирует код `RD1…`) и вставьте его там.

## 4. Здоровье утром (до 9:00)
iOS не даёт сайтам читать «Здоровье», поэтому его читает ваша команда **«Планировщик»** (сборка по шагам — `SETUP_HEALTH.md`, ~10 минут) и отправляет в облако по адресу из вкладки «Здоровье». Автозапуск: *«Будильник → Остановлен»* и запасной *«Время суток 08:30»*, оба «Запускать сразу». Приложение при открытии само забирает данные.
> Пока iPhone заблокирован, iOS не отдаёт данные «Здоровья» никому, поэтому надёжнее всего срабатывает «будильник остановлен» (телефон только что разблокирован). Запасной платный вариант без сборки команды — Health Auto Export (в том же файле).

## 5. Что с чем синхронизируется
| Откуда | Куда | Когда |
|---|---|---|
| Google Календарь (все выбранные календари, без праздников и отклонённых) | Расписание дня | при запуске, при возврате в приложение, раз в 10 мин, по кнопке 🔄 |
| Google Задачи (на сегодня, просроченные, до 15 без срока) | Банк задач | так же |
| «Выполнено» / новая задача в приложении | Google Задачи (видно на телефоне) | сразу; офлайн — при следующей синхронизации |
| Здоровье (команда «Планировщик») | Заряд батареи | по автозапуску из пункта 4 |
| Состояние приложения | Облако, все устройства | автоматически |

Ограничения: сервер читает только **Google** Календарь и Задачи. Календарь iCloud и «Напоминания» Apple — нет: добавьте Google-аккаунт (Настройки iPhone → Календарь → Учётные записи) и храните события/задачи там, либо пользуйтесь приложением «Google Задачи».

## 6. Если что-то не так
| Видите | Причина → решение |
|---|---|
| «сервер устарел» | вставьте новый `Code.gs` и сделайте **новую версию** развёртывания |
| «сервис Google Tasks API не включён» | вставьте `appsscript.json` и снова запустите `setup()` |
| «Календарь: ошибка / нет разрешения» | запустите `setup()` и разрешите доступ, затем новая версия развёртывания |
| «токен не совпадает» | запустите `showToken()` в скрипте и вставьте тот же токен |
| «Данные за вчера» | запустите команду «Планировщик» (кнопка в подсказке) или проверьте Health Auto Export |
| Событий нет, а в Google они есть | событие в календаре, который скрыт («не выбран») в Google Календаре, или отклонено вами |

## 7. Безопасность
Токен — как пароль. Если он попал на скриншот: `resetToken()` → новая версия развёртывания → вставьте новый токен в приложение и в Health Auto Export / команду. На экране приложения токен скрыт (••••).
