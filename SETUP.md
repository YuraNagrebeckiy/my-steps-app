# Облако для «Ритма Дня» через Google Apps Script

## Шаг 1. Создать сервер (5 минут, один раз)
1. Откройте https://script.google.com → **Новый проект**.
2. Удалите всё в редакторе и вставьте содержимое файла `Code.gs`.
3. В первой строке замените `СМЕНИТЕ_НА_ДЛИННУЮ_СЛУЧАЙНУЮ_СТРОКУ` на свой пароль (токен): 20+ символов, буквы и цифры. Запомните его.
4. **Развернуть → Новое развёртывание → тип «Веб-приложение»**
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
5. Нажмите «Развернуть», разрешите доступ к Google Диску (нужен, чтобы хранить файл `ritm-dnya-state.json`). Если появится «Приложение не проверено» — **Дополнительно → Перейти (небезопасно)**: это ваш собственный скрипт.
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

> Если позже измените `Code.gs`: **Развернуть → Управление развёртываниями → ✏ → Новая версия**. Без этого работает старый код.

## Шаг 2. Загрузить файлы на GitHub
Замените в репозитории `my-steps-app`: `index.html`, `script.js`, `style.css`, `sw.js`, `manifest.json` (+ иконки). Дважды обновите страницу.

## Шаг 3. Подключить приложение
Откройте приложение → **🔄 Синхронизировать** → блок **☁ Облако** → вставьте URL и токен → **🔌 Подключить**.
Нужно сделать один раз в Safari и один раз в иконке на рабочем столе (у них раздельное хранилище, но теперь данные общие через облако).

## Шаг 4. Команда «Планировщик» на iPhone
В конце команды вместо «Открыть URL с параметрами» сделайте:
1. **Получить содержимое URL** → метод GET, адрес вида  
   `ВАШ_URL/exec?action=ingest&token=ТОКЕН&sleep=…&deep=…&bedtime=…&calories=…&steps=…&hr=…`  
   (значения подставляйте переменными из «Здоровья»; готовый образец ссылки с вашим токеном — на вкладке «Здоровье», кнопка копирования).  
   Необязательно: `&cal=10:00-11:00|Встреча; 14:00-15:00|Созвон` и `&tasks=Задача 1; Задача 2`.
2. **Открыть URL** → ссылка на приложение (`https://yuranagrebeckiy.github.io/my-steps-app/`).

При открытии приложение само заберёт данные из облака и заполнит заряд, расписание и задачи.

## Как это работает
- Приложение хранит копию состояния в облаке; побеждает более свежая версия (по времени изменения).
- Данные команды (`ingest`) применяются один раз и только если пришли сегодня.
- Без интернета приложение работает локально и синхронизируется при следующем открытии.
- Токен хранится только на устройстве и в вашем `Code.gs`, в облачную копию состояния не попадает.
- Безопасность: адрес `/exec` знает только вы; без токена сервер ничего не отдаёт. Не публикуйте ссылку с токеном.
